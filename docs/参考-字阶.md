# 参考字阶（COUI）

字号全部取自参考 APK 的 `res/values/styles.xml`（couiText\*）与 dimens，不要再自定。

| 用途 | 参考 token | 字号 | App 里的 typography |
| --- | --- | --- | --- |
| 首页大标题 | `coui_appbar_title_expanded_text_size` / `coui_appbar_title_collapsed_text_size` | 32dp → 24dp | `headlineLarge` + `copy(32.sp)`，收起缩放 0.75 |
| 分类胶囊、文件夹名 | 胶囊文字 16sp、高 34dp | 16sp medium | `titleMedium` |
| 弹层/面板标题 | `couiTextHeadlineM` | 20sp | `headlineMedium` |
| 小标题、面板左标题（格式 / 添加） | `couiTextHeadlineS` | 18sp | `titleLarge` |
| 卡片标题、设置行标题 | `couiTextHeadlineXS` / `note_item_title_text_size` | 16sp medium | `titleMedium` |
| 按钮文字（完成 / 关闭） | `couiTextButtonM` | 14sp medium | `titleSmall` |
| 正文、卡片内容、时间与分组 | `couiTextBodyM` / `sp_14` / `grid_item_content_text_size` | 14sp | `bodyMedium`、`labelMedium` |
| 说明、编辑器时间行、图标格子标签 | `couiTextBodyXS` / `dp_12` | 12sp | `bodySmall`、`labelSmall` |

行高按参考的行距倍数：headline 1.1、body 1.1、bodyXS 1.0。

编辑器里的字号是内容不是 UI：标题 24sp/600、正文 16sp、H1 24 / H2 20 / H3 16 / 注释 14（见 `docs/参考-编辑页.md`），不随上面这档缩放。

首页大标题收起后 = 24dp，即 32dp × 0.75（`coui_appbar_title_collapsed_text_size`）。

自定义字号以后在设置里做，届时以这里为 100% 基准。
