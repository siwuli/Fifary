## 1. 页面骨架 `layout/fragment_wv_note_view_edit_phone.xml`

```
DispatchTouchEventFrameLayout note_edit_content
├ ConstraintLayout rich_linearlayout (vertical)
│ ├ ContentFrameLayout content_layout  ← include richEditor（WebView 富文本，见第 6 节）
│ └ NoteTimeLinearLayout note_time      ← 「2026/10/28 00:23 | 默认」
├ AppBarBlurOverlayView blur_overlay    ← 顶栏后面是真的模糊
└ COUIDividerAppBarLayout appBarLayout
  └ FrameLayout tool_bar_layout
    └ COUIToolbar toolbar
      ├ layout_center_toolbar_normal_btns / _table_btns
      └ AdaptiveIconContainer adaptive_undo_redo_container
```

顶栏按钮来自 `menu/menu_note_edit_bar.xml`：`menu_undo`、`menu_redo`（默认 `visible=false`，有历史才出现）、`menu_send_note`(分享)、`menu_encrypt`、`menu_move_folder`、`menu_delete_note` 等（后几个 `showAsAction=never`，进 ⋮）。回到列表是 COUIToolbar 的返回箭头，保存是「完成」。
→ 我此前把「预览」塞进顶栏是自造，参考里没有预览模式。

## 2. 时间行

`NoteTimeLinearLayout`，文案 `yyyy/MM/dd HH:mm  |  <分组名>`，`bodySmall`、次要色，左边距 24dp（对齐标题块的 paddingStart 24）。

## 3. 标题块 `layout/item_rich_note_title.xml`

hint「标题」、24sp、weight 600、paddingStart 24dp / end 20dp / top 16dp / bottom 14dp、minHeight 45dp、maxLength 50。

## 4. 正文 `layout/item_rich_note_text.xml`

16sp `sans-serif-regular`、paddingStart/End = `common_margin`、paddingBottom 12dp、占位「输入文本，键入“/”快速调整格式」。
正文是 **WebView 里的 TipTap 富文本**（`WVRichEditor`，`assets/tiptap/assets/index.js` 858KB），不是 Compose 里的 Markdown 原文。

## 5. 底部气泡 `layout/note_bottom_toolbar.xml`

`COUIBottomFloatingEditToolbar id=bottom_menu`，菜单在代码里拼。尺寸（`values/dimens.xml`）：

- `coui_bottom_floating_edit_toolbar_item_height_horizontal` = 40dp
- `coui_bottom_floating_edit_toolbar_item_max_width_horizontal` = 98dp
- `inner_padding_horizontal` 10dp / `inner_padding_vertical` 12dp
- `menu_height_medium_large` 44dp / `single_item_width_horizontal` 152dp
- 左右留白 `padding_horizontal_small_screen` 16dp（中等屏 24、大屏 40）
- 展开/收起用 `COUISpringAnimation`（弹簧），不是淡入淡出

## 7. 「格式」面板 `layout/rich_text_tool_panel_layout.xml`

表头（`layout/toolbar_panel.xml`）：标题「格式」左 20dp、`couiTextHeadlineS`，右上 ✕ 24dp、右 16dp，两者都在 50dp guideline 之上。

四排（每项高 `toolbar_item_height` 44dp）：

1. **文字样式**（`text_style_title/subtitle/small_title/body_text/annotation_text`），标签直接按各自字号显示：
   标题 24sp/600、副标题 20sp/600、小标题 16sp/600、正文 16sp、注释 14sp
2. **字符样式**：加粗 · 斜体 · 删除线 ‖ 文字底色 + 取色 ‖ 下划线 + 取色 ‖ 波浪线 + 取色
3. **段落**：无序列表 · 有序列表 ‖ 增加缩进 · 减少缩进 ‖ 居中 · 右对齐
4. **其它**：分割线 ‖ 字体（当前字体名）‖ 字号 ‖ 字色

横向可滚动，左右两端有渐隐遮罩（`left_fade` / `right_fade`）。
